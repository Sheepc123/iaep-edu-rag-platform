# 智能教育平台后端架构设计文档 v1.0

### 基本信息
- **项目名称**: 智能教育平台后端API

- **开发状态**: 架构设计完成，准备模块开发
- **文档版本**: v1.0
- **最后更新**: 2024-06-24

### 设计目标
- **高内聚低耦合**: 模块化设计，功能独立

## 📊 数据库设计

### 数据表关系图
```
Users (用户表)
├── StudentProfile (学生档案)
├── TeacherProfile (教师档案)
├── UserSession (用户会话)
└── UserActivity (用户活动)

Courses (课程表)
├── Lesson (课时表)
├── CourseEnrollment (课程注册)
├── LessonProgress (课时进度)
└── StudyPlan (学习计划)

Exercises (练习表)
├── Question (题目表)
├── ExerciseAttempt (练习尝试)
├── StudentAnswer (学生答案)
├── WrongQuestion (错题本)
└── ExerciseStatistics (练习统计)

Chat (聊天表)
├── ChatRoom (聊天室)
├── ChatMember (聊天成员)
├── ChatMessage (聊天消息)
└── UserContact (用户联系人)

AI (AI助手表)
├── AIConversation (AI对话)
├── AIMessage (AI消息)
├── AIRecommendation (AI推荐)
└── UserOnlineStatus (在线状态)
```

### 核心数据表设计

#### 1. 用户相关表
- **users**: 用户基础信息，支持学生/教师/管理员角色
- **student_profiles**: 学生详细档案，学习统计数据
- **teacher_profiles**: 教师详细档案，教学统计数据
- **user_sessions**: 用户会话管理，支持多设备登录
- **user_activities**: 用户活动记录，用于数据分析

#### 2. 课程相关表
- **courses**: 课程基本信息，评分统计
- **lessons**: 课时详细内容，支持多种类型
- **course_enrollments**: 学生课程注册，进度跟踪
- **lesson_progress**: 课时学习进度，支持断点续看
- **study_plans**: 个性化学习计划

#### 3. 练习相关表
- **exercises**: 练习集管理，支持多种练习类型
- **questions**: 题目库，支持选择题/填空题/问答题
- **exercise_attempts**: 练习尝试记录，完整答题过程
- **student_answers**: 学生答案详情，支持评分
- **wrong_questions**: 错题本，智能复习推荐

#### 4. 聊天相关表
- **chat_rooms**: 聊天室管理，支持私聊/群聊
- **chat_members**: 聊天室成员，权限管理
- **chat_messages**: 消息记录，支持多媒体
- **user_contacts**: 联系人管理

#### 5. AI相关表
- **ai_conversations**: AI对话会话管理
- **ai_messages**: AI消息记录，支持评分反馈
- **ai_recommendations**: AI智能推荐记录
- **user_online_status**: 用户在线状态
