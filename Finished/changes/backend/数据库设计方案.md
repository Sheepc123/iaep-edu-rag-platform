# 智能教育实训平台数据库设计方案

## 📋 设计概述

基于智能教育实训平台的功能需求，设计高效、可扩展的数据库架构，支持用户管理、课程学习、AI对话、实时聊天等核心功能。

## 🎯 设计原则

1. **数据一致性**：确保ACID特性，保证数据完整性
2. **高性能**：合理的索引设计，支持高并发访问
3. **可扩展性**：支持水平扩展和垂直扩展
4. **安全性**：敏感数据加密，权限控制严格
5. **易维护性**：清晰的表结构，完善的约束关系

## 🗄️ 数据库选型

### 主数据库：PostgreSQL 15+
- **ACID保证**：强一致性事务支持
- **JSON支持**：灵活存储复杂数据结构
- **全文搜索**：内置搜索功能
- **向量搜索**：pgvector扩展支持AI embedding
- **分区支持**：大表分区优化性能

### 缓存数据库：Redis 7+
- **会话缓存**：用户登录状态
- **对话缓存**：AI对话历史
- **实时数据**：在线用户、消息队列
- **限流控制**：API访问频率限制

## 📊 核心表结构设计

### 1. 用户管理模块

#### 用户表 (users)
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(20) NOT NULL DEFAULT 'student' CHECK (role IN ('student', 'teacher', 'admin')),
    status VARCHAR(20) NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'suspended')),
    
    -- 个人信息
    full_name VARCHAR(100),
    avatar_url VARCHAR(500),
    phone VARCHAR(20),
    school VARCHAR(100),
    college VARCHAR(100),
    student_id VARCHAR(50),
    
    -- 系统字段
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_login_at TIMESTAMP WITH TIME ZONE,
    email_verified_at TIMESTAMP WITH TIME ZONE,
    
    -- 索引
    CONSTRAINT users_email_check CHECK (email ~* '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$')
);

-- 索引
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_role ON users(role);
CREATE INDEX idx_users_status ON users(status);
CREATE INDEX idx_users_created_at ON users(created_at);
```

#### 用户配置表 (user_preferences)
```sql
CREATE TABLE user_preferences (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- AI助手偏好
    ai_language VARCHAR(10) DEFAULT 'zh-CN',
    ai_response_style VARCHAR(20) DEFAULT 'detailed' CHECK (ai_response_style IN ('concise', 'detailed', 'friendly')),
    ai_subjects TEXT[], -- 感兴趣的学科
    ai_difficulty VARCHAR(20) DEFAULT 'medium' CHECK (ai_difficulty IN ('easy', 'medium', 'hard')),
    
    -- 界面偏好
    theme VARCHAR(20) DEFAULT 'light' CHECK (theme IN ('light', 'dark', 'auto')),
    language VARCHAR(10) DEFAULT 'zh-CN',
    timezone VARCHAR(50) DEFAULT 'Asia/Shanghai',
    
    -- 通知偏好
    email_notifications BOOLEAN DEFAULT true,
    push_notifications BOOLEAN DEFAULT true,
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    UNIQUE(user_id)
);
```

### 2. 课程管理模块

#### 课程表 (courses)
```sql
CREATE TABLE courses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(200) NOT NULL,
    description TEXT,
    cover_image_url VARCHAR(500),
    
    -- 课程信息
    teacher_id UUID NOT NULL REFERENCES users(id),
    category VARCHAR(50),
    difficulty VARCHAR(20) CHECK (difficulty IN ('beginner', 'intermediate', 'advanced')),
    duration_hours INTEGER DEFAULT 0,
    
    -- 课程内容 (JSON格式存储)
    content JSONB,
    objectives TEXT[],
    prerequisites TEXT[],
    
    -- 状态管理
    status VARCHAR(20) DEFAULT 'draft' CHECK (status IN ('draft', 'published', 'archived')),
    is_featured BOOLEAN DEFAULT false,
    
    -- 统计信息
    enrolled_count INTEGER DEFAULT 0,
    rating DECIMAL(3,2) DEFAULT 0.00,
    rating_count INTEGER DEFAULT 0,
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    published_at TIMESTAMP WITH TIME ZONE
);

-- 索引
CREATE INDEX idx_courses_teacher_id ON courses(teacher_id);
CREATE INDEX idx_courses_category ON courses(category);
CREATE INDEX idx_courses_status ON courses(status);
CREATE INDEX idx_courses_featured ON courses(is_featured);
CREATE INDEX idx_courses_rating ON courses(rating DESC);
```

#### 课程注册表 (course_enrollments)
```sql
CREATE TABLE course_enrollments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    course_id UUID NOT NULL REFERENCES courses(id) ON DELETE CASCADE,
    
    -- 学习进度
    progress DECIMAL(5,2) DEFAULT 0.00 CHECK (progress >= 0 AND progress <= 100),
    completed_lessons INTEGER DEFAULT 0,
    total_lessons INTEGER DEFAULT 0,
    
    -- 时间记录
    enrolled_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_accessed_at TIMESTAMP WITH TIME ZONE,
    completed_at TIMESTAMP WITH TIME ZONE,
    
    -- 学习统计
    total_study_time INTEGER DEFAULT 0, -- 总学习时间（分钟）
    
    UNIQUE(user_id, course_id)
);

-- 索引
CREATE INDEX idx_enrollments_user_id ON course_enrollments(user_id);
CREATE INDEX idx_enrollments_course_id ON course_enrollments(course_id);
CREATE INDEX idx_enrollments_progress ON course_enrollments(progress);
```

### 3. AI对话模块

#### 对话表 (conversations)
```sql
CREATE TABLE conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(200) DEFAULT '新对话',
    
    -- 对话统计
    message_count INTEGER DEFAULT 0,
    total_tokens INTEGER DEFAULT 0,
    
    -- 状态管理
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'archived', 'deleted')),
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_message_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_conversations_user_id ON conversations(user_id);
CREATE INDEX idx_conversations_status ON conversations(status);
CREATE INDEX idx_conversations_last_message ON conversations(last_message_at DESC);
```

#### 消息表 (messages)
```sql
CREATE TABLE messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
    
    -- 消息内容
    content TEXT NOT NULL,
    sender VARCHAR(10) NOT NULL CHECK (sender IN ('user', 'ai')),
    message_type VARCHAR(20) DEFAULT 'text' CHECK (message_type IN ('text', 'image', 'file', 'suggestion', 'exercise')),
    
    -- AI相关元数据
    metadata JSONB, -- 存储tokens、model、confidence等信息
    
    -- 消息状态
    status VARCHAR(20) DEFAULT 'sent' CHECK (status IN ('sent', 'delivered', 'read', 'failed')),
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_messages_conversation_id ON messages(conversation_id);
CREATE INDEX idx_messages_created_at ON messages(created_at);
CREATE INDEX idx_messages_sender ON messages(sender);

-- 分区表（按月分区，提高查询性能）
CREATE TABLE messages_y2024m01 PARTITION OF messages
    FOR VALUES FROM ('2024-01-01') TO ('2024-02-01');
```

### 4. 聊天室模块

#### 聊天室表 (chat_rooms)
```sql
CREATE TABLE chat_rooms (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(100) NOT NULL,
    description TEXT,
    room_type VARCHAR(20) DEFAULT 'group' CHECK (room_type IN ('private', 'group', 'class')),
    
    -- 房间设置
    max_members INTEGER DEFAULT 100,
    is_public BOOLEAN DEFAULT false,
    
    -- 创建者信息
    created_by UUID NOT NULL REFERENCES users(id),
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 聊天室成员表 (chat_room_members)
```sql
CREATE TABLE chat_room_members (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    room_id UUID NOT NULL REFERENCES chat_rooms(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- 成员角色
    role VARCHAR(20) DEFAULT 'member' CHECK (role IN ('owner', 'admin', 'member')),
    
    -- 状态信息
    joined_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_read_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    UNIQUE(room_id, user_id)
);
```

#### 聊天消息表 (chat_messages)
```sql
CREATE TABLE chat_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    room_id UUID NOT NULL REFERENCES chat_rooms(id) ON DELETE CASCADE,
    sender_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- 消息内容
    content TEXT NOT NULL,
    message_type VARCHAR(20) DEFAULT 'text' CHECK (message_type IN ('text', 'image', 'file', 'system')),
    
    -- 消息状态
    is_deleted BOOLEAN DEFAULT false,
    edited_at TIMESTAMP WITH TIME ZONE,
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_chat_messages_room_id ON chat_messages(room_id);
CREATE INDEX idx_chat_messages_sender_id ON chat_messages(sender_id);
CREATE INDEX idx_chat_messages_created_at ON chat_messages(created_at DESC);
```

### 5. 练习系统模块

#### 练习题表 (exercises)
```sql
CREATE TABLE exercises (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(200) NOT NULL,
    description TEXT,
    
    -- 题目信息
    question_type VARCHAR(20) NOT NULL CHECK (question_type IN ('multiple_choice', 'fill_blank', 'essay', 'code')),
    difficulty VARCHAR(20) DEFAULT 'medium' CHECK (difficulty IN ('easy', 'medium', 'hard')),
    subject VARCHAR(50),
    topic VARCHAR(100),
    
    -- 题目内容 (JSON格式)
    content JSONB NOT NULL,
    answer JSONB NOT NULL,
    explanation TEXT,
    
    -- 关联信息
    course_id UUID REFERENCES courses(id),
    created_by UUID NOT NULL REFERENCES users(id),
    
    -- 统计信息
    attempt_count INTEGER DEFAULT 0,
    correct_rate DECIMAL(5,2) DEFAULT 0.00,
    
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 练习记录表 (exercise_attempts)
```sql
CREATE TABLE exercise_attempts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    exercise_id UUID NOT NULL REFERENCES exercises(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- 答题信息
    user_answer JSONB NOT NULL,
    is_correct BOOLEAN NOT NULL,
    score DECIMAL(5,2) DEFAULT 0.00,
    
    -- 时间记录
    started_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    submitted_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    time_spent INTEGER DEFAULT 0 -- 用时（秒）
);

-- 索引
CREATE INDEX idx_attempts_exercise_id ON exercise_attempts(exercise_id);
CREATE INDEX idx_attempts_user_id ON exercise_attempts(user_id);
CREATE INDEX idx_attempts_submitted_at ON exercise_attempts(submitted_at DESC);
```

### 3. 视图定义
```sql
-- 用户学习统计视图
CREATE VIEW user_learning_stats AS
SELECT 
    u.id as user_id,
    u.full_name,
    COUNT(DISTINCT ce.course_id) as enrolled_courses,
    AVG(ce.progress) as avg_progress,
    SUM(ce.total_study_time) as total_study_time,
    COUNT(DISTINCT ea.exercise_id) as exercises_attempted,
    AVG(CASE WHEN ea.is_correct THEN 1.0 ELSE 0.0 END) as success_rate
FROM users u
LEFT JOIN course_enrollments ce ON u.id = ce.user_id
LEFT JOIN exercise_attempts ea ON u.id = ea.user_id
WHERE u.role = 'student'
GROUP BY u.id, u.full_name;

-- AI对话统计视图
CREATE VIEW ai_conversation_stats AS
SELECT 
    c.user_id,
    COUNT(*) as total_conversations,
    SUM(c.message_count) as total_messages,
    SUM(c.total_tokens) as total_tokens,
    AVG(c.message_count) as avg_messages_per_conversation,
    MAX(c.last_message_at) as last_interaction
FROM conversations c
WHERE c.status = 'active'
GROUP BY c.user_id;
```

## 🚀 Redis缓存设计

### 1. 缓存键命名规范
```
# 用户会话
session:{user_id} -> {session_data}

# AI对话缓存
ai:conversation:{conversation_id} -> {messages_list}
ai:user:{user_id}:recent -> {recent_conversations}

# 在线用户
online:users -> {set_of_user_ids}
online:user:{user_id} -> {user_status}

# 聊天室
chatroom:{room_id}:members -> {set_of_user_ids}
chatroom:{room_id}:messages -> {recent_messages_list}

# API限流
ratelimit:{user_id}:{endpoint} -> {request_count}
```
