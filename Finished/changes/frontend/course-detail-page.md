# 课程详情页面开发文档

## 📋 功能概述

### 页面信息
- **页面名称**: 课程详情页面 (CourseDetail.tsx)
- **路由路径**: `/student/courses/:courseId`
- **开发状态**: ✅ 完成开发
- **最后更新**: 2024-06-24

### 功能定位
为学生提供完整的课程详情展示，包括课程信息、学习进度、课程内容、教师介绍和学习资料，支持课程注册和学习进度跟踪。

## 🎯 核心功能

### 1. 课程信息展示
- ✅ **课程封面**: 高质量课程封面图片展示
- ✅ **基本信息**: 课程标题、难度、分类、评分等
- ✅ **统计数据**: 注册学生数、课程时长、评分信息
- ✅ **课程描述**: 详细的课程介绍和学习目标

### 2. 学习进度管理
- ✅ **进度显示**: 可视化学习进度条和完成度
- ✅ **课时统计**: 已完成课时数/总课时数
- ✅ **注册状态**: 区分已注册和未注册状态
- ✅ **快速操作**: 继续学习、注册课程按钮

### 3. 课程内容结构
- ✅ **课时列表**: 完整的课程课时列表展示
- ✅ **学习状态**: 课时完成状态、进度百分比
- ✅ **访问控制**: 基于注册状态和学习进度的访问权限
- ✅ **课时类型**: 视频、文档等不同类型课时标识
- ✅ **免费试听**: 免费课时标识和访问

### 4. 教师信息展示
- ✅ **教师资料**: 教师姓名、头像、简介
- ✅ **教学统计**: 课程评分、注册学生数、评价数量
- ✅ **联系方式**: 联系教师、教师主页链接

### 5. 学习资料下载
- ✅ **资料列表**: 课程相关学习资料展示
- ✅ **文件信息**: 文件名、大小、类型显示
- ✅ **下载功能**: 一键下载学习资料
- ✅ **使用说明**: 下载和使用注意事项

## 🏗️ 技术实现

### 组件结构
```
CourseDetail.tsx
├── 页面头部 (返回按钮)
├── 课程封面区域
├── 学习进度卡片
└── 标签页内容
    ├── 课程概述
    ├── 课程内容
    ├── 授课教师
    └── 课程资料
```

### 状态管理
```typescript
const [course, setCourse] = useState<Course | null>(null);
const [lessons, setLessons] = useState<Lesson[]>([]);
const [enrollment, setEnrollment] = useState<CourseEnrollment | null>(null);
const [lessonProgresses, setLessonProgresses] = useState<LessonProgress[]>([]);
const [loading, setLoading] = useState(true);
```

### API集成
- **课程信息**: `courseAPI.getCourse(courseId)`
- **课程课时**: `courseAPI.getCourseLessons(courseId)`
- **注册信息**: `courseAPI.getCourseEnrollment(courseId)`
- **学习进度**: `courseAPI.getCourseProgress(courseId)`
- **课程注册**: `courseAPI.enrollCourse(courseId)`

## 🔗 页面导航

### 入口路径
1. **课程中心**: 点击课程卡片的"详情"按钮
2. **课程中心**: 点击课程卡片的"继续学习"按钮
3. **直接访问**: URL路径 `/student/courses/:courseId`

### 出口路径
1. **返回按钮**: 返回课程中心页面
2. **开始学习**: 跳转到具体课时学习页面（待开发）
3. **联系教师**: 跳转到聊天或联系页面（待开发）

## 🔒 权限控制

### 访问权限
- **游客**: 可查看课程基本信息和免费课时
- **注册学生**: 可查看完整课程内容和学习进度
- **未注册学生**: 显示注册提示和注册按钮

### 课时访问
- **免费课时**: 所有用户可访问
- **付费课时**: 需要注册课程后访问
- **顺序学习**: 按课时顺序解锁访问权限

## 📊 数据流程

### 页面加载流程
```
1. 获取路由参数 courseId
2. 并行请求课程数据
   ├── 课程基本信息
   ├── 课程课时列表
   ├── 注册信息（可选）
   └── 学习进度（可选）
3. 更新页面状态
4. 渲染页面内容
```

### 课程注册流程
```
1. 用户点击注册按钮
2. 调用注册API
3. 更新注册状态
4. 刷新页面数据
5. 显示成功提示
```
