## 🎨 设计系统

### 动画设计原则
1. **渐进式增强** - 基础功能优先，动画作为增强
2. **性能优化** - 使用GPU加速的transform属性
3. **用户体验** - 提供视觉反馈和状态指示
4. **一致性** - 统一的动画时长和缓动函数

### 色彩方案
- **主色调**: 紫色到蓝色渐变 (`from-purple-600 to-blue-600`)
- **辅助色**: 绿色、橙色、灰色系
- **状态色**: 成功(绿)、警告(黄)、错误(红)

### 组件规范
- **卡片**: 圆角16px，阴影效果，悬浮动画
- **按钮**: 渐变背景，缩放动画，状态反馈
- **输入框**: 圆角设计，焦点状态，边框动画
