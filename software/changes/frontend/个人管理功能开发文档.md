# 个人管理功能开发文档

## 功能概述

个人管理功能为学生用户提供完整的个人信息管理和账户安全设置，包括基本信息编辑、密码修改等核心功能。

## 访问路径

- **导航方式**：左侧导航栏底部 → 点击用户头像 → 账户设置
- **路由地址**：`/student/profile`
- **页面组件**：`src/pages/student/Profile.tsx`

## 功能特性

### 1. 个人信息管理
- **基本信息展示**：头像、姓名、学号、学校、学院
- **联系信息**：邮箱、电话号码
- **在线编辑**：支持实时编辑和保存
- **数据验证**：表单输入验证和错误提示

### 2. 账户安全管理
- **密码修改**：当前密码验证 + 新密码设置
- **密码强度提示**：安全建议和规则说明
- **密码可见性切换**：支持显示/隐藏密码
- **安全状态显示**：密码安全等级、两步验证状态

### 3. 用户体验优化
- **响应式设计**：适配桌面和移动端
- **动画效果**：流畅的页面加载和交互动画
- **实时反馈**：保存状态提示和错误处理
- **表单验证**：实时输入验证和友好提示

## 核心功能实现

### 1. 个人信息编辑
```typescript
const handleSaveProfile = async () => {
  setIsSaving(true);
  try {
    // API调用保存个人信息
    await updateUserProfile(editForm);
    setProfile(editForm);
    setIsEditing(false);
    setSaveMessage({ type: 'success', text: '个人信息更新成功！' });
  } catch (error) {
    setSaveMessage({ type: 'error', text: '更新失败，请稍后重试。' });
  } finally {
    setIsSaving(false);
    setTimeout(() => setSaveMessage(null), 3000);
  }
};
```

### 2. 密码修改
```typescript
const handleChangePassword = async () => {
  // 密码验证
  if (passwordForm.newPassword !== passwordForm.confirmPassword) {
    setSaveMessage({ type: 'error', text: '新密码与确认密码不匹配！' });
    return;
  }

  if (passwordForm.newPassword.length < 6) {
    setSaveMessage({ type: 'error', text: '新密码长度至少6位！' });
    return;
  }

  setIsSaving(true);
  try {
    // API调用修改密码
    await changePassword({
      currentPassword: passwordForm.currentPassword,
      newPassword: passwordForm.newPassword
    });
    
    // 重置表单
    setPasswordForm({ currentPassword: "", newPassword: "", confirmPassword: "" });
    setShowPasswordForm(false);
    setSaveMessage({ type: 'success', text: '密码修改成功！' });
  } catch (error) {
    setSaveMessage({ type: 'error', text: '密码修改失败，请检查当前密码是否正确。' });
  } finally {
    setIsSaving(false);
    setTimeout(() => setSaveMessage(null), 3000);
  }
};
```

### 3. 表单验证
```typescript
// 邮箱格式验证
const validateEmail = (email: string): boolean => {
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return emailRegex.test(email);
};

// 手机号格式验证
const validatePhone = (phone: string): boolean => {
  const phoneRegex = /^1[3-9]\d{9}$/;
  return phoneRegex.test(phone);
};

// 密码强度检查
const checkPasswordStrength = (password: string): string => {
  if (password.length < 6) return 'weak';
  if (password.length >= 8 && /[A-Z]/.test(password) && /[0-9]/.test(password)) {
    return 'strong';
  }
  return 'medium';
};
```
