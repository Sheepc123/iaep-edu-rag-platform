# AI助手功能开发文档

## 功能概述

AI助手是智能教育实训平台的核心功能之一，为学生提供智能化的学习辅导和问答服务。该功能支持两种访问方式：
1. **右下角浮动按钮**：在任何学生页面都可以快速访问
2. **导航栏AI助手页面**：提供完整的对话管理界面

## 技术架构

### 核心组件结构
```
src/
├── contexts/
│   └── AIContext.tsx           # AI对话状态管理
├── components/
│   └── ai/
│       ├── AIChat.tsx          # 浮动AI对话组件
│       ├── FloatingAIButton.tsx # 右下角浮动按钮
│       └── SimpleAIButton.tsx   # 简化版AI按钮
└── pages/
    └── student/
        └── AIAssistant.tsx     # AI助手完整页面
```

### 状态管理架构

使用React Context实现全局状态管理，确保两种访问方式共享相同的对话历史。

#### AIContext 接口定义
```typescript
interface Message {
  id: string;
  content: string;
  sender: 'user' | 'ai';
  timestamp: Date;
  type?: 'text' | 'suggestion' | 'exercise';
}

interface Conversation {
  id: string;
  title: string;
  messages: Message[];
  lastUpdated: Date;
}

interface AIContextType {
  conversations: Conversation[];
  currentConversationId: string;
  currentMessages: Message[];
  isTyping: boolean;
  // ... 其他方法
}
```

## 功能特性

### 1. 对话管理
- **多对话支持**：用户可以创建多个独立的对话会话
- **对话历史**：自动保存所有对话记录
- **对话切换**：在左侧面板快速切换不同对话
- **对话删除**：支持删除不需要的对话（至少保留一个）

### 2. 智能回复
- **上下文理解**：基于用户输入内容提供相关回复
- **学习领域识别**：识别数学、学习计划、练习等关键词
- **个性化建议**：根据学习情况提供针对性建议

### 3. 用户体验
- **实时输入状态**：显示AI正在思考的动画效果
- **快速操作**：提供学习指导、解题帮助等快捷按钮
- **消息操作**：支持复制、点赞、点踩等交互
- **响应式设计**：适配不同屏幕尺寸
