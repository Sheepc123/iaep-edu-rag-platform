# 高等数学极限理论

## 第一章 极限的概念

### 1.1 数列极限的定义

#### 1.1.1 直观理解
数列极限描述的是数列项随着项数无限增大时的趋势。如果数列 {aₙ} 的项随着 n 的增大而无限接近某个确定的数 A，则称 A 为数列 {aₙ} 的极限。

#### 1.1.2 ε-N 定义
设 {aₙ} 为一数列，A 为一常数。如果对于任意给定的正数 ε，总存在正整数 N，使得当 n > N 时，恒有
|aₙ - A| < ε

则称常数 A 是数列 {aₙ} 的极限，记作：
lim(n→∞) aₙ = A 或 aₙ → A (n → ∞)

#### 1.1.3 几何意义
数列极限的几何意义是：对于任意小的正数 ε，在 A 的 ε 邻域 (A-ε, A+ε) 外，数列 {aₙ} 最多只有有限项。

### 1.2 函数极限的定义

#### 1.2.1 自变量趋于无穷时的极限
设函数 f(x) 在 |x| 大于某一正数时有定义。如果对于任意给定的正数 ε，总存在正数 X，使得当 |x| > X 时，恒有
|f(x) - A| < ε

则称常数 A 是函数 f(x) 当 x → ∞ 时的极限，记作：
lim(x→∞) f(x) = A

#### 1.2.2 自变量趋于有限值时的极限
设函数 f(x) 在点 x₀ 的某一去心邻域内有定义。如果对于任意给定的正数 ε，总存在正数 δ，使得当 0 < |x - x₀| < δ 时，恒有
|f(x) - A| < ε

则称常数 A 是函数 f(x) 当 x → x₀ 时的极限，记作：
lim(x→x₀) f(x) = A

#### 1.2.3 单侧极限
**左极限**：lim(x→x₀⁻) f(x) = A₁，当 x 从左侧趋于 x₀ 时的极限
**右极限**：lim(x→x₀⁺) f(x) = A₂，当 x 从右侧趋于 x₀ 时的极限

**定理**：lim(x→x₀) f(x) = A 的充分必要条件是左极限和右极限都存在且相等，即：
lim(x→x₀⁻) f(x) = lim(x→x₀⁺) f(x) = A

## 第二章 极限的性质

### 2.1 极限的基本性质

#### 2.1.1 唯一性
如果数列 {aₙ} 的极限存在，那么极限唯一。

**证明思路**：用反证法，假设有两个不同的极限，利用 ε-N 定义导出矛盾。

#### 2.1.2 有界性
如果数列 {aₙ} 收敛，那么数列 {aₙ} 一定有界。

**注意**：有界是收敛的必要条件，但不是充分条件。

#### 2.1.3 保号性
设 lim(n→∞) aₙ = A，且 A > 0（或 A < 0），则存在正整数 N，当 n > N 时，有 aₙ > 0（或 aₙ < 0）。

### 2.2 极限的运算法则

设 lim(n→∞) aₙ = A，lim(n→∞) bₙ = B，则：

1. **加减法则**：lim(n→∞) (aₙ ± bₙ) = A ± B
2. **乘法法则**：lim(n→∞) (aₙ · bₙ) = A · B
3. **除法法则**：lim(n→∞) (aₙ / bₙ) = A / B（B ≠ 0）
4. **常数倍法则**：lim(n→∞) (c · aₙ) = c · A（c 为常数）

### 2.3 夹逼定理（三明治定理）

如果数列 {aₙ}、{bₙ}、{cₙ} 满足：
1. 从某项起，有 aₙ ≤ bₙ ≤ cₙ
2. lim(n→∞) aₙ = lim(n→∞) cₙ = A

则 lim(n→∞) bₙ = A

**应用示例**：
证明 lim(n→∞) sin(n)/n = 0

由于 -1 ≤ sin(n) ≤ 1，所以 -1/n ≤ sin(n)/n ≤ 1/n
而 lim(n→∞) (-1/n) = lim(n→∞) (1/n) = 0
由夹逼定理得 lim(n→∞) sin(n)/n = 0

## 第三章 重要极限

### 3.1 第一个重要极限

lim(x→0) (sin x)/x = 1

#### 3.1.1 几何证明
利用单位圆中扇形面积的比较：
当 0 < x < π/2 时，有 sin x < x < tan x
两边同时除以 sin x 得：1 < x/sin x < 1/cos x
取倒数：cos x < sin x/x < 1
当 x → 0 时，cos x → 1，由夹逼定理得 lim(x→0) (sin x)/x = 1

#### 3.1.2 相关极限
1. lim(x→0) (tan x)/x = 1
2. lim(x→0) (arcsin x)/x = 1
3. lim(x→0) (arctan x)/x = 1
4. lim(x→0) (1 - cos x)/x² = 1/2

### 3.2 第二个重要极限

lim(x→∞) (1 + 1/x)ˣ = e
或等价形式：lim(x→0) (1 + x)^(1/x) = e

其中 e ≈ 2.71828...（自然对数的底）

#### 3.2.1 相关极限
1. lim(n→∞) (1 + 1/n)ⁿ = e
2. lim(x→0) (1 + x)^(1/x) = e
3. lim(x→∞) (1 + k/x)ˣ = eᵏ
4. lim(x→0) (aˣ - 1)/x = ln a（a > 0, a ≠ 1）

## 第四章 无穷小与无穷大

### 4.1 无穷小的概念

#### 4.1.1 定义
如果函数 f(x) 当 x → x₀（或 x → ∞）时的极限为零，那么称函数 f(x) 为当 x → x₀（或 x → ∞）时的无穷小。

#### 4.1.2 无穷小的性质
1. 有限个无穷小的和仍是无穷小
2. 有界函数与无穷小的乘积是无穷小
3. 有限个无穷小的乘积仍是无穷小

### 4.2 无穷小的比较

设 α 和 β 都是同一自变量变化过程中的无穷小，且 α ≠ 0：

1. 如果 lim α/β = 0，则称 α 是比 β 高阶的无穷小，记作 α = o(β)
2. 如果 lim α/β = ∞，则称 α 是比 β 低阶的无穷小
3. 如果 lim α/β = c ≠ 0，则称 α 与 β 是同阶无穷小
4. 如果 lim α/β = 1，则称 α 与 β 是等价无穷小，记作 α ~ β

### 4.3 常用等价无穷小（当 x → 0 时）

1. sin x ~ x
2. tan x ~ x
3. arcsin x ~ x
4. arctan x ~ x
5. ln(1 + x) ~ x
6. eˣ - 1 ~ x
7. (1 + x)ᵅ - 1 ~ αx
8. 1 - cos x ~ x²/2

### 4.4 无穷大的概念

#### 4.4.1 定义
设函数 f(x) 在 x₀ 的某一去心邻域内有定义。如果对于任意给定的正数 M，总存在正数 δ，使得当 0 < |x - x₀| < δ 时，恒有 |f(x)| > M，则称函数 f(x) 为当 x → x₀ 时的无穷大。

#### 4.4.2 无穷大与无穷小的关系
在自变量的同一变化过程中，如果 f(x) 为无穷大，则 1/f(x) 为无穷小；反之，如果 f(x) 为无穷小，且 f(x) ≠ 0，则 1/f(x) 为无穷大。

## 第五章 函数的连续性

### 5.1 连续性的定义

#### 5.1.1 在一点处的连续性
设函数 f(x) 在点 x₀ 的某一邻域内有定义，如果
lim(x→x₀) f(x) = f(x₀)

则称函数 f(x) 在点 x₀ 处连续。

#### 5.1.2 连续的充分必要条件
函数 f(x) 在点 x₀ 处连续的充分必要条件是：
lim(x→x₀⁻) f(x) = lim(x→x₀⁺) f(x) = f(x₀)

### 5.2 间断点的分类

#### 5.2.1 第一类间断点
左极限和右极限都存在的间断点：
1. **可去间断点**：左极限 = 右极限 ≠ f(x₀)
2. **跳跃间断点**：左极限 ≠ 右极限

#### 5.2.2 第二类间断点
左极限和右极限至少有一个不存在的间断点：
1. **无穷间断点**：左极限或右极限为无穷大
2. **振荡间断点**：左极限或右极限振荡不存在

### 5.3 连续函数的性质

#### 5.3.1 连续函数的运算
设函数 f(x) 和 g(x) 在点 x₀ 处连续，则：
1. f(x) ± g(x) 在点 x₀ 处连续
2. f(x) · g(x) 在点 x₀ 处连续
3. f(x)/g(x) 在点 x₀ 处连续（g(x₀) ≠ 0）

#### 5.3.2 复合函数的连续性
设 y = f[g(x)]，如果 u = g(x) 在点 x₀ 处连续，y = f(u) 在点 u₀ = g(x₀) 处连续，则复合函数 y = f[g(x)] 在点 x₀ 处连续。

### 5.4 闭区间上连续函数的性质

#### 5.4.1 最大值和最小值定理
在闭区间 [a, b] 上连续的函数 f(x) 一定有最大值和最小值。

#### 5.4.2 介值定理
设函数 f(x) 在闭区间 [a, b] 上连续，且 f(a) ≠ f(b)，那么对于 f(a) 与 f(b) 之间的任意一个数 C，在开区间 (a, b) 内至少存在一点 ξ，使得 f(ξ) = C。

#### 5.4.3 零点定理
设函数 f(x) 在闭区间 [a, b] 上连续，且 f(a) · f(b) < 0，那么在开区间 (a, b) 内至少存在一点 ξ，使得 f(ξ) = 0。

## 第六章 极限的计算方法

### 6.1 利用极限运算法则

对于简单的有理函数，可以直接利用极限的四则运算法则。

**例题**：计算 lim(x→2) (x² - 4)/(x - 2)

解：原式 = lim(x→2) (x + 2)(x - 2)/(x - 2) = lim(x→2) (x + 2) = 4

### 6.2 利用重要极限

#### 6.2.1 第一重要极限的应用
**例题**：计算 lim(x→0) sin(3x)/x

解：原式 = lim(x→0) [sin(3x)/(3x)] · 3 = 1 · 3 = 3

#### 6.2.2 第二重要极限的应用
**例题**：计算 lim(x→∞) (1 + 2/x)ˣ

解：原式 = lim(x→∞) [(1 + 2/x)^(x/2)]² = e² 

### 6.3 利用等价无穷小替换

当 x → 0 时，可以用等价无穷小进行替换简化计算。

**例题**：计算 lim(x→0) (1 - cos x)/x²

解：因为 1 - cos x ~ x²/2（当 x → 0 时）
所以原式 = lim(x→0) (x²/2)/x² = 1/2

### 6.4 洛必达法则

#### 6.4.1 法则内容
设函数 f(x) 和 g(x) 满足：
1. 在点 a 的某去心邻域内可导，且 g'(x) ≠ 0
2. lim(x→a) f(x) = lim(x→a) g(x) = 0 或 ∞
3. lim(x→a) f'(x)/g'(x) 存在（或为无穷大）

则 lim(x→a) f(x)/g(x) = lim(x→a) f'(x)/g'(x)

#### 6.4.2 应用示例
**例题**：计算 lim(x→0) (eˣ - 1 - x)/x²

解：这是 0/0 型未定式，应用洛必达法则：
原式 = lim(x→0) (eˣ - 1)/(2x) = lim(x→0) eˣ/2 = 1/2

### 6.5 泰勒展开

利用函数的泰勒展开式可以简化极限计算。

常用的泰勒展开（x → 0）：
1. eˣ = 1 + x + x²/2! + x³/3! + ...
2. sin x = x - x³/3! + x⁵/5! - ...
3. cos x = 1 - x²/2! + x⁴/4! - ...
4. ln(1 + x) = x - x²/2 + x³/3 - ...

**例题**：计算 lim(x→0) (eˣ - 1 - x - x²/2)/x³

解：利用 eˣ 的泰勒展开：
eˣ = 1 + x + x²/2 + x³/6 + o(x³)
所以 eˣ - 1 - x - x²/2 = x³/6 + o(x³)
原式 = lim(x→0) [x³/6 + o(x³)]/x³ = 1/6

## 第七章 典型例题与解法

### 7.1 数列极限

**例题1**：证明 lim(n→∞) (√(n+1) - √n) = 0

证明：√(n+1) - √n = (√(n+1) - √n)(√(n+1) + √n)/(√(n+1) + √n)
= 1/(√(n+1) + √n) < 1/(2√n)

因为 lim(n→∞) 1/(2√n) = 0，由夹逼定理得原极限为 0。

### 7.2 函数极限

**例题2**：计算 lim(x→1) (x³ - 1)/(x² - 1)

解：这是 0/0 型未定式
原式 = lim(x→1) (x - 1)(x² + x + 1)/[(x - 1)(x + 1)]
= lim(x→1) (x² + x + 1)/(x + 1) = 3/2

### 7.3 无穷小比较

**例题3**：当 x → 0 时，比较无穷小 α = x - sin x 与 β = x³ 的阶

解：lim(x→0) (x - sin x)/x³
利用泰勒展开：sin x = x - x³/6 + o(x³)
所以 x - sin x = x³/6 + o(x³)
原式 = lim(x→0) [x³/6 + o(x³)]/x³ = 1/6
因此 α 与 β 是同阶无穷小。

### 7.4 连续性问题

**例题4**：讨论函数 f(x) = {x sin(1/x), x ≠ 0; 0, x = 0} 在 x = 0 处的连续性

解：需要验证 lim(x→0) f(x) = f(0)
因为 |x sin(1/x)| ≤ |x|，而 lim(x→0) |x| = 0
由夹逼定理得 lim(x→0) x sin(1/x) = 0 = f(0)
所以函数在 x = 0 处连续。

## 总结

极限理论是高等数学的基础，主要包括：

1. **基本概念**：数列极限和函数极限的定义
2. **重要性质**：唯一性、有界性、保号性
3. **运算法则**：四则运算、夹逼定理
4. **重要极限**：两个基本重要极限及其应用
5. **计算方法**：等价无穷小、洛必达法则、泰勒展开
6. **连续性**：函数连续的概念和性质

掌握这些内容对于后续学习微分、积分等内容至关重要。
